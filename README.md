# SigeonOS: BreadCrumb Release

The unofficial Sigeon Operating System BreadCrumb release source code. <br>
Any questions, suggestions or reporting something are happily accepted on [Discord](https://discord.gg/X9Sp5nJMPF)

-----------------------------------

> The operating system is still actively being worked.

#### Current features:
- Finder/File Explorer
- Terminal
- SigeonWeb/Browser
- Goon Message/Messaging app
- Notes app
- Clock
- .. and alot more ..

#### Issues
SigeonOS has its fair share of issues like most OS's, like it does not support every network, it likely UI bugs, etc.
While those issues exist, you or we can and will find and resolve the issues and errors found within the source code.
If you want to report any issues, please contact us on Discord or on the Issues tab on this repository.

#### Pro's
Barely uses any hardware resources <br>
(nearly) Useful for daily activities <br>
Supports older hardware <br>
(really it I could think of😭)

#### Con's
Most software does not support SigeonOS <br>
May be unreliable in some situations <br>
Uncommon bugs
